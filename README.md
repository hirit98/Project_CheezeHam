## 1. 프로젝트 소개
> "CheezeHam"은 사용자 간 소통과 정보 공유를 위한 인터넷 카페 웹 애플리케이션입니다..<br />
> 회원 가입 및 로그인을 통해 사용자는 게시글 작성, 댓글, 좋아요 등 다양한 커뮤니케이션 기능을 사용할 수 있습니다.<br />
> 관리자 페이지를 통해 카페 운영자가 게시판과 사용자 권한을 효율적으로 관리할 수 있습니다. <br />
> Java와 Spring Boot를 기반으로 제작되었으며, 데이터 관리는 Mysql을 사용했습니다.

> #### 개발 기간 및 인원
> 24.07.11 ~ 24.08.15 (약 5주) <br />
> 백엔드 2명 <br />
> 시연영상 Link : https://youtu.be/9btHTm1Uob0 <br />
